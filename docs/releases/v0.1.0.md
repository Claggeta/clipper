# Clipper v0.1.0

First release. Clipper is a command-line tool that finds clip-worthy moments
in a local video file. Everything runs locally.

## What it does

`clipper analyze <video>` extracts the audio with ffmpeg, transcribes it with
faster-whisper, scores sliding windows of the transcript with a heuristic
detector, and reports the top 5 candidates. Each has a start, an end, a score
and the reasons behind it. It prints a table and saves the result as JSON
(default `data/output/`). Transcripts are cached in `data/cache/`.

Settings come from environment variables: `CLIPPER_WHISPER_MODEL`,
`CLIPPER_TOP_N`, `CLIPPER_CACHE_DIR`, `CLIPPER_OUTPUT_DIR`. `-v` shows
progress logging.

Install from source. See the [README](../../README.md) for requirements, usage
and sample output.

## Pinned dependencies

`av==17.0.0` and `huggingface-hub<1.0`. faster-whisper 1.2.1 calls
`av.open(..., metadata_errors="ignore")`, which av 19.0.2 rejects, and
huggingface-hub 2.x changed its API and dependency graph. See
[ADR 0003](../decisions/0003-pin-transcription-dependencies.md) before
unpinning either.

## What was checked

CI runs ruff, mypy (strict) and pytest. It cannot run real ffmpeg or a real
Whisper model, so before this release the manual checklist was run once:
2026-10-30, Windows 11, ffmpeg 9.0.2-full_build-www.gyan.dev, Whisper `base`
on CPU. Every step behaved as documented. That is what was observed on that
one setup, not a guarantee for other platforms or ffmpeg builds.

Measured on a 5:14 speech video, `base` model, CPU: 14.3 s cold (model already
downloaded) and 0.4 s with a transcript cache hit.

## Known limitations

- Weak signals on Whisper `base` output. The model omits much punctuation, so
  the question and exclamation signals rarely fire. Scores cluster low and the
  pace signal carries most of the weight.
- On Windows, ffmpeg exit codes are shown as unsigned 32-bit numbers, for
  example `3199971767`. The error message itself is readable.
- Long videos are unmeasured. Only the 5:14 video above has been timed.
- The output JSON is named after the video's file name, so two videos with the
  same name overwrite each other's output.
- Audio with no speech exits 0, prints an empty table and saves a JSON file
  with no candidates.

## Not in this release
